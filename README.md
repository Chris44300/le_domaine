# Le Domaine

Interface maîtresse personnelle de Chris : un écran d'accueil façon
téléphone (grille de "pièces"), une barre de recherche connectée à un
majordome LLM, et un cœur métier Python partagé avec le bot Telegram
"Nigel" — un seul cerveau, plusieurs façons d'y accéder.

Le détail complet (contexte, décisions d'architecture actées, plan de
construction phase par phase) est dans [`PLAN.md`](PLAN.md) — à lire en
premier avant toute contribution ou reprise de session.

## Projets liés

- **Nigel** (`../Projet - Assistant IA (Nigel)/assistant-ia-personnel`) —
  le bot Telegram, source du futur cœur métier exposé en API.
- **Ménage** (`../Projet - Taches ménage/Application Tâches ménagères`) —
  application Next.js/Supabase déjà en production, première pièce du
  Domaine.
