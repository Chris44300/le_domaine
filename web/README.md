# Le Domaine — app web (Next.js)

Voir le [README à la racine du dépôt](../README.md) pour ce que c'est,
l'architecture, et comment lancer/déployer le projet en entier.
`../PLAN.md` couvre le pourquoi et l'historique des décisions.

Ce sous-dossier est un projet Next.js standard (App Router, généré à
l'origine avec `create-next-app`) : `npm install`, `npm run dev`,
`app/page.tsx` comme point d'entrée de l'accueil. Rien de spécifique à
documenter ici au-delà du README racine.
